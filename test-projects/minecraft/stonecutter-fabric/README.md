# Stonecutter Fabric

A minimal multi-version Fabric project using Stonecutter 0.4.5 for Minecraft 1.20.1 and 1.21.
Run `buildAllVersions` to verify version fan-out, per-version properties, Loom dependencies, and
mod JAR assembly for both targets.

The layout is based on patterns used by the [Stonecutter Fabric template](https://github.com/stonecutter-versioning/stonecutter-template-fabric),
[YetAnotherConfigLib](https://github.com/isXander/YetAnotherConfigLib), and
[Weathering Chamber](https://github.com/vincentvella/weathering-chamber).
